# FMSH.RU

Source code for a future version of [FMSH.RU](https://fmsh.ru/), the website of a physics and mathematics school offering additional education in mathematics, physics, and computer science.

Built with **PHP, HTML, CSS, and JavaScript**. The website includes information about the school and its teachers, admissions, an event calendar, registration forms, and a class timetable.

Development primarily focused on the frontend. The PHP backend included in this repository is a simplified version of the backend used by the actual website.

To run locally, serve the project directory using a PHP-enabled web server (for example, `php -S localhost:8000`).
