# FMSH.RU

Source code for [FMSH.RU](https://fmsh.ru/), the website of a physics and mathematics school offering additional education in mathematics, physics, and computer science.

Built with **PHP, HTML, CSS, and JavaScript**. The site includes information about the school and teachers, admissions, an event calendar, registration forms, and a class timetable.

To run locally, serve the project directory with a PHP-enabled web server (for example, `php -S localhost:8000`).
